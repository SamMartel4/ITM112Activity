# School Management System

## About the Project
The School Management System is a web-based application developed using Laravel. It helps manage school records and information efficiently.

## Features
- Student Management
- Teacher Management
- Subject Management
- Class Management
- User Registration and Login
- Dashboard

## Technologies Used
- Laravel
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Installation
1. Clone the repository.
2. Run `composer install`.
3. Copy `.env.example` and rename the copy to `.env`.
4. Run `php artisan key:generate`.
5. Configure your database in `.env`.
6. Run `php artisan migrate`.
7. Start the server using `php artisan serve`.
